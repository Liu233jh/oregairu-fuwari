本站的[语录页](/quotes/)目前收录 **158 条**语录，覆盖雪乃、结衣、八幡、一色、平冢老师等 13 个角色。

它们不是手打的，而是从原著全文自动提取出来的。

## 数据源

| 指标 | 数值 |
|---|---|
| 总字符数 | 3,434,814 |

## 提取流程

### 第一步：抓对话行

原著用直角引号包裹对话：

```
「怎么可能。就算我们能互称熟人、认识的人、朋友，或是同学，我不觉得自己能好好维持那样的关系。」
```

一条正则就能抓出全部 31,042 条。

### 第二步：过滤

- 长度 10–70 字（太短没信息，太长不像语录）
- 剔除纯动作描写（「他说道」「点点头」之类）
- 按前 20 字去重

剩下 22,061 条。

### 第三步：评分

按主题关键词加分：

| 主题 | 关键词 |
|---|---|
| 青春 | 青春、人生、成长 |
| 孤独 | 孤独、一个人、朋友 |
| 真诚 | 真话、撒谎、谎言、真心 |
| 努力 | 努力、加油、放弃、坚持 |
| 人际关系 | 关系、距离、依赖、信任、误会 |
| 自我 | 自己、自我、改变 |

再加上长度偏好（25–55 字最佳）和标点特征。

## ⚠️ 踩过的坑：角色归属

这是最麻烦的部分。

**第一版我用「前后各取几行，看有没有角色名」**——结果 400 条里 315 条识别不出来。

### 问题出在哪

我以为对话的上一行是「XX 说道：」，实际上——**上一行是空行**。

小说的排版是这样的：

```
正当我沉浸在恐怖的回忆时，雪之下朗声宣告：     ← 真正的归属行
                                                 ← 空行
「富者本着慈悲之心施与贫者，这就是所谓的公益。」  ← 对话
                                                 ← 空行
不知不觉中，雪之下已站起身，自然形成从上方俯瞰我的姿态。
```

段落之间用空行分隔，所以「上一行」永远是空的。

### 修正

改成**找上一个非空行**，然后按优先级判断：

| 优先级 | 规则 | 置信度 |
|---|---|---|
| P1 | 上一个非空行以 `：` 结尾且含角色名 | 3 |
| P1b | 上一个非空行含「角色名 + 说/道/宣告」 | 3 |
| P2 | 下一个非空行含「角色名 + 说话动词」 | 2 |
| P2b | 上下出现第一人称说话（八幡主视角） | 2 |
| P3 | 上下两行内出现角色名 | 1 |

**只保留置信度 ≥ 2 的**——宁可少标，不要标错。

## 已知问题

**归属仍有误差。** 启发式规则只能做到这个程度——比如某句明明是阳乃说的，但因为上一行恰好提到了雪乃，就被归到了雪乃名下。

要彻底解决，需要：
1. 人工逐条校对，或
2. 用 LLM 做归属判断（输入上下文，让模型判断说话人）

对于 Demo 阶段，目前的准确率已经可用，页面底部也标注了「归属经启发式识别，可能存在误差」。

## 技术栈

- **提取**：Python 正则 + 启发式规则
- **存储**：Astro Content Collections（Markdown）
- **筛选**：纯 CSS `display` 切换 + 少量原生 JS，**没有引入任何框架**
- **搜索**：前端 `includes()` 匹配
