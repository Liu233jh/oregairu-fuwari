关于本站#

一个纯本地自用的春物主题站 —— 用来整理原著语录、记录阅读随笔，顺便放几个会动的角色。

它是什么#

板块内容
博客14 篇春物相关的导读、逐季编年、角色分析与阅读随笔
语录库450 条语录，其中 177 条精选；可按角色 / 主题筛选，也能关键词搜索
角色页3 个角色接入 Live2D（雪之下雪乃 / 由比滨结衣 / 一色彩羽），可切换服装、姿态、表情与 27 个动作；另有 3 个角色位显示「敬请期待」
首页全屏 4K 壁纸开屏（打字机标语 + 日语金句轮播 + 樱花飘落），下方是整幅通栏的全员群像
搜索页内搜索合并两路：语录（450 条，客户端） + 文章（Pagefind）

语录是怎么来的#

不是随手抄的，是分档挑过、又砍过两轮的：

档来源条数
A网络正典 → 定位到小说卷次14
Bmoegirl 等站的「语录」小节（人工可核）141
—从 343 万字原著全文中提取并人工筛的272
—手工精挑的金句（f*.md）23
  • 砍掉了 134 条启发式 C 档 —— 机器打分够不上「值得单独拿出来」的水平，宁可少不掺水
  • 删掉了 19 条角色归属错误（如「雪之下的问题应该由雪之下自己解决」其实是八幡说的）
  • 雪乃 / 结衣的「她说」板块各 6 条金句；一色只有 2 条 —— 她的语录池里确实没有真金句，不硬凑

详细规则见 README 的「语录系统」一节。

配色#

本站的「粉蓝双色」不是拍脑袋定的，而是来自两个已有的雪乃实现：

来源主色OKLCH hue用在哪
雪乃桌宠（Windows 版）#62b6ff 蓝247°信息层：导航、链接、博客、语录
DSH 插件 yukinoDigital#f77fa8 粉360°情感层：角色页
桥梁#7b6cf6 紫284°标签、焦点、渐变过渡

分工原则：粉和蓝不在同一视觉区域竞争。

  • 博客 / 语录 → 只有蓝
  • 角色页 → 每个角色用自己的印象色（雪乃蓝 / 结衣粉 / 一色黄）
  • 首页开屏 → 蓝系 + 青色壁纸，唯一让粉蓝同现的地方是日语金句的渐变字

深色与浅色两套配色都做过对比度审计（WCAG），深色下已无低对比度文字。
